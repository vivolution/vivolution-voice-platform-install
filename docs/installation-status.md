# Installation status

The stable channel remains intentionally unavailable. The immutable `v0.1.0-rc12` preview is the signed unified Controller and Edge pilot candidate and is available only through its version-pinned bootstrap.

RC12 supports one standalone Controller and separately hosted Edge Appliances. It must not be represented as a Controller-HA, public-production, billing-grade, or certified SBC release. The remaining acceptance boundaries are listed in its release notes.
